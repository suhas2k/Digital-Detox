# 🌿 Digital Detox — Take Back Your Attention

A beautifully crafted, modern website designed to help you step back from screen overload, cultivate mindfulness, and build healthy, intentional relationships with technology.

---

## ✨ Features & Highlights

- **Pure & Lightweight:** Built using clean HTML5, custom CSS3, and Vanilla JavaScript — zero bloated frameworks or external runtime dependencies.
- **🌗 Universal Theme Switching:** Instant Light & Dark mode toggle with zero flash of unstyled content (anti-FOUC) and `localStorage` persistence.
- **📱 Fully Responsive:** Carefully optimized for mobile, tablet, and ultra-wide desktop displays.
- **🎨 Modern Aesthetic:** Elegant typography featuring Google Fonts (*Outfit* & *Plus Jakarta Sans*), subtle glassmorphism, smooth micro-interactions, and high-quality photography.
- **🚀 Ready for GitHub Pages:** Zero build steps required — host effortlessly on GitHub Pages or any static web host.

## 🚀 Getting Started

### Option 1: Open Directly in Browser
Simply double-click `index.html` (or run `run.bat` on Windows) to open the website in your default browser.

### Option 2: Live Server or Local HTTP Server
You can serve the directory with any static server:
```bash
# Using Python
python -m http.server 8080

# Using Node / npx
npx serve .
```
Then navigate to `http://localhost:8080`.

---

## 🌐 Deploy to GitHub Pages

1. Go to your repository settings on GitHub: **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Choose the `main` branch and `/ (root)` folder.
4. Click **Save**. Your site will be live at `https://suhas2k.github.io/Digital-Detox/`!
